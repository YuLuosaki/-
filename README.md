# 你像哪个历史人物 · H5 测试

一个纯本地的单页人格测试。16 道单选，六维模型，六位历史人物原型。

**无需服务器、无需网络请求、无第三方 CDN** —— 下载后断网也能完整运行。

## 在线体验

打开 `index.html` 即可（本地双击或用浏览器打开）。

## 文件结构

```
index.html   入口，含全部样式
data.js      题库、人物原型、解析文案
app.js       计分与渲染逻辑
使用说明.md   部署方式、内容红线、改内容与重新校准的方法
```

三个文件需放在同一目录，`index.html` 直接打开即可使用。

## 功能

- 16 道单选题，六维模型（决断 / 谋略 / 内省 / 亲和 / 破格 / 退隐）
- 输出相似度百分比、六维对照条形图、全部候选原型排行
- 每个原型 4 条**带文献出处**的对照解析（正史与传世文献，非演义）
- 三条差异提示 + 三条行动建议 + 一句原文引文
- 分享卡（canvas 生成 PNG，可下载）
- 结果文案一键复制

## 内容说明

人物生平论断逐条核对原始文献，每条解析均标注出处：

| 原型 | 主要依据 |
|---|---|
| 诸葛亮 | 《三国志·蜀书·诸葛亮传》、《出师表》、《诫子书》 |
| 武则天 | 《旧唐书·则天皇后纪》、《新唐书》、《资治通鉴·唐纪》 |
| 王阳明 | 《传习录》、《王阳明年谱》 |
| 曾国藩 | 《曾国藩家书》、《曾国藩日记》 |
| 陶渊明 | 《宋书·隐逸传·陶潜》、《归去来兮辞》、《饮酒》 |
| 上官婉儿 | 《旧唐书·上官婉儿传》、《新唐书·上官婉儿传》 |

题库与解析为原创撰写，不套用任何商业心理量表题面。
本测试为趣味化自我探索工具，不构成心理学诊断或历史人物性格还原。

## 修改内容

题库、解析文案在 `data.js`。修改人物基准向量 `vec` 后需重新校准六人分布，
方法见 `使用说明.md` 第七节（含可运行的校准脚本与判断标准）。
